# あといくら

今月あといくら使えるかを、すぐに確認できる家計簿Webアプリです。

## できること

- 月の予算と残り金額を確認
- 支出・収入の追加、編集、削除
- 予算消化と月の進み具合を比較
- 支出カテゴリ別の内訳を確認
- 月移動とカテゴリ絞り込み
- ブラウザ内への自動保存

## 使い方

`index.html` をブラウザで開くだけで使えます。データは利用中のブラウザの `localStorage` に保存され、外部には送信されません。

GitHub Pages: https://gakkii415.github.io/kakeibo/

## 今回の試作範囲

依存関係のない静的なMVPです。認証、銀行・カード連携、クラウド同期、複数端末共有は含みません。
